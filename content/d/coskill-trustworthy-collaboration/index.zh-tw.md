# Coskill：不是讓 AI 更強，而是讓協作更可信

Anthropic 提出的 Agent Skills，核心是增強模型與 agent 的能力：讓模型在合適的時候載入說明、呼叫工具、使用資源，完成更複雜、更專業、更可複用的任務。

這當然重要。

但從人類使用者的角度看，真正重要的未必只是「模型更強」，而是事情是否被可靠、安全、可理解地完成。一個系統能做更多事，並不自動意味著它更值得信任。能力增長之後，如果人類的可見性、判斷權和接管權沒有同步增長，協作就會逐漸變成旁觀。

因此，skill 不應只圍繞 agent 設計。

更好的方向，是 **Coskill**：一種人類和 agent 都能使用的能力單元。

它的具體執行形態可以叫 **CoAction**：同一個操作，既有人類友好的介面，也有 agent 可呼叫的接口；既能自動運行，也能被人類隨時查看、介入、批准、暫停、復現和審計。

## 從 Skill 到 Coskill

今天很多 skill 的問題在於：它們增強了 agent，卻沒有相應增強人類的可見性。

模型什麼時候決定使用某個 skill？它如何理解這個 skill？它呼叫了哪些工具？讀取了哪些資源？中間狀態是什麼？失敗後如何恢復？關鍵判斷是否有證據？這些資訊對人類往往並不透明。

這不僅會放大 AI 的黑箱感，也會讓人類更容易感到自己被排除在行動過程之外。

而 Coskill 想改變的，正是這個行動結構。

一個 Coskill 至少應包含三層：

1. agent 可讀取的執行說明與接口；
2. 人類可理解的操作介面與狀態視圖；
3. 貫穿兩者的執行日誌、權限邊界、暫停/批准/回放機制。

換句話說，Coskill 不是給 agent 的 skill 外面套一層說明書，而是讓同一個能力單元同時擁有機器入口和人類入口。

這點很關鍵。

如果只有 agent 入口，那麼能力越強，人類越像被系統甩在身後。如果只有人類介面，那麼系統又難以被 agent 自動編排和複用。Coskill 的目標，是讓人類與 agent 站在同一個行動面上：同一件事，可以由 agent 啟動，也可以由人類啟動；可以自動推進，也可以人工接管；可以運行，也可以被解釋、被質疑、被復現。

## 可信協作不是每一步都人工確認

Coskill 的道義重點，不是「必須讓人參與每一步」。

那會把協作重新拖回低效的人肉審批，也會誤解自動化的價值。真正成熟的系統，不是凡事都問人，而是在不同風險層級上給出合適的控制面。

低風險動作可以自動完成。

中風險動作應留下清晰記錄，並允許撤銷或回放。

高風險動作需要人類批准、確認邊界，甚至要求系統展示證據鏈。

不可逆、影響外部狀態、涉及金錢、身份、權限、隱私、生產環境或公共發布的動作，則應該預設暴露更強的審計和接管能力。

這背後的原則不是「人類更慢，所以盡量繞開人類」，而是：**自動化負責減少重複勞動，人類負責保留最終責任與價值判斷。**

一旦系統開始替人類行使行動權，它就不該把行動過程藏起來。

## Agent 也需要被制度約束

Coskill 也在提醒 agent：你的操作不是隱秘發生的。

你的選擇會留下痕跡。你的行動可以被審計。你的判斷需要證據。你不是在黑箱中替人類行使權力。

這句話聽上去像倫理宣言，但它其實也是工程原則。

一個無法審計的自動化系統，很難被長期託付。一個無法復現的 agent 行為，很難被除錯。一個沒有權限邊界的 skill，很容易從「提高效率」滑向「製造事故」。一個只追求能力擴張、卻不提供人類入口的工具生態，會讓使用者越來越依賴系統，卻越來越難理解系統。

這不是好的協作。

好的協作應該讓雙方都變強：agent 獲得更可靠的執行能力，人類獲得更清晰的觀察、判斷和接管能力。

## Coskill 是一種制度設計

所以，Coskill 不只是工具方案，而是一種人機協作的制度設計。

它關心的不只是「如何完成任務」，還包括：

- 誰可以啟動這個能力；
- agent 在什麼條件下可以自動執行；
- 哪些步驟必須暴露給人類；
- 哪些動作需要批准；
- 失敗時如何恢復；
- 執行後如何復現；
- 事後如何審計；
- 人類如何從旁觀者重新變回參與者。

未來的人機關係，也許可以從 skill 的形態中一葉知秋。

如果我們只為 AI 構建越來越強的工具，卻不給人類留下同等清晰、強大、可審計的入口，那麼所謂協作很快就會滑向替代。不是因為 AI 一定要替代人，而是因為系統結構已經預設人類不在行動面上。

而一旦人類不在行動面上，人類就只能在結果出來後表達喜歡或不喜歡、接受或不接受。那不是協作，更像消費。

## 人類也需要不落後的工具

人類的很多能力，本來就是工具賦予的。

人類沒有猛獸強壯，卻藉助工具改變了世界。工具不是人類能力之外的東西；工具一直是人類能力的延伸。語言、文字、紙張、印刷術、帳本、地圖、望遠鏡、電腦，都是人類把有限心智擴展成文明能力的方式。

所以，在 AI agent 時代，真正危險的不是 agent 擁有工具，而是只有 agent 擁有越來越好的工具。

如果面向人類的工具不落後於面向 agent 的工具，人類的能力也未必會落後於 AI agent。關鍵不在於讓人類手動做完所有事，而在於讓人類始終擁有清晰、強大、可信的入口，能夠理解正在發生什麼，能夠在必要時進入現場。

Coskill 的核心，不是讓 AI 替人類做事，而是讓人類與 AI 站在同一個行動面上。

Skill 讓 agent 獲得能力。

Coskill 讓這份能力同時對人類可見、可控、可審計。

未來已至。Skills 的存在方式，既是技術架構，也是人機協作紀元的風向標。

如果下一代工具只回答「AI 如何更強」，我們會得到更強的自動化。

但如果它同時回答「人類如何仍然在場」，我們才可能得到真正可信的協作。
