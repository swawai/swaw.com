# 关于人不工

我们在做一人工作室的 AI 驾驶舱：从网络与开发环境起步，逐步把内容运营、税务记账等繁琐事务整理成可复用、可自动化的工作系统，让人专注于创作和品味。

人不工，是 Swaw 在中文语境里的名字。

它来自「人工」的反向提醒：人不必沦为工具。

Swaw 有两层含义：Stay Whole At Work / See Work As Weather。在工作中保持人性的完整，像看天气一样观察工作。

## 目前进展

现阶段，仍在早期，更适合关注、试用和反馈。如果你也关心 AI 进入工作流之后，一人工作室的工作方式，欢迎把使用场景和问题发给我。这些反馈会帮助我把产品打磨得更清楚。

已经整理出来的产品有：


- [ruletab](/p/ruletab/)：为隐私保护者和多网络环境工作者设计。支持按应用指派代理出口，让网络切换更稳、更可控。  
- [xvenv](/p/xvenv/)：一键拉起免安装的开发环境，让 AI Agent 更快进入可用状态，也让 `.env` 与 Git 身份管理更省心。


## 为什么是我

我做过近 8 年图书管理员，后来转行，从事过网管、运维开发、数据爬虫、游戏创业合伙人和自由职业者。

这些经历让我长期关注：信息的整理与复用，工具的可靠与低摩擦。

期间我也写小说、做游戏 Mod。

人不工不是凭空想出来的产品概念，而是我先为自己搭建工作系统，再把稳定、有复用价值的部分产品化。
