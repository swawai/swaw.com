# 关于Swaw

Swaw 取意于 **S**ee **W**hat **A**ctually **W**orks：看清什么真正有效。

我们在做一人工作室的 AI 驾驶舱：

从网络与开发环境起步，逐步把行业信号观测、内容运营、财税记账等繁琐事务，整理成可复用、可自动化的工作系统，让人把注意力留给判断和品味。


## 目前进展

项目仍在早期。

如果你也关注 AI 进入工作流后，独立个体如何组织自己的工作，欢迎把具体场景和问题发给我。这些反馈会帮助我把产品打磨得更清楚。

已经整理出来的产品有：

- Ruletab (准备中)：为隐私保护者和多网络环境工作者设计。支持按应用指派代理出口，让多网络切换更稳、更可控。
- [Xvenv](/p/xvenv/)：一键拉起免安装的开发环境，让 AI Agent 更快进入可用状态，也让 `.env` 与 Git 身份管理更省心。


## 为什么是我

我做过近 8 年图书馆员，后来转入技术领域，做过网管、运维开发、数据爬虫，也参与过游戏创业。

这些经历让我长期关注两件事：知识的整理与复用，工具的顺手与可靠。

期间我也写小说、做游戏 Mod。目前是自由职业者，居住在中国深圳。

Swaw 不是凭空想出来的产品概念，而是我先为自己搭建工作系统，再把其中稳定、有复用价值的部分产品化。
